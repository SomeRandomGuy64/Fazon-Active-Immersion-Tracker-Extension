    Import from Mikan 見間
    1. Open Mikan’s dashboard.
    2. Press F12 and open the Console tab.
    3. Run this — it copies your history to the clipboard:
      chrome.storage.local.get('watchData', d => copy(JSON.stringify(d)))
    4. Paste it below (or save it to a .json file and choose it).

    Mikan’s days are merged into your history here. Imported history isn’t sent to your fazon.nexus Track — only time recorded by this extension is.

    Reset

    Delete all recorded time and overrides from this browser. Time already synced to fazon.nexus stays there. Export first if you might want it back.
